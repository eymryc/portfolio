# Adaptation par secteur — Portfolio as a Service

La solution propose une **structure unique** (profil, compétences, expériences, projets, formation, contact) que chaque secteur utilise à sa façon. Aucun champ n’est obligatoire : on remplit ce qui correspond à son métier.

---

## 1. Métiers du numérique et design

**Profils :** Graphistes, infographistes, web designers, développeurs web/logiciels, UX/UI designers.

| Section   | Usage typique |
|----------|----------------|
| **Profil** | Nom, titre (ex. "Développeur full-stack"), bio, photo, liens LinkedIn / GitHub / site / Behance / Dribbble. |
| **Compétences** | Catégories : Langages, Frameworks, Outils, Design (Figma, etc.). |
| **Expériences** | Postes en entreprise, freelance, stages. |
| **Projets** | Projets perso ou pro : titre, description, lien (démo, repo), tags (React, Node, etc.). |
| **Formation** | Écoles, bootcamps, certifications. |
| **Contact** | Email, téléphone, formulaire. |

## Principes communs

- **Projets** = réalisations, créations, campagnes, travaux : la section la plus polyvalente (titre, description, lien, image, tags).
- **Expériences** = parcours professionnel ou artistique (rôle, entreprise/client, période).
- **Compétences** = catégories libres (texte ou listes) selon le métier.
- **Formation** = optionnelle pour les secteurs où le parcours académique compte moins.
- Les **liens** du profil (LinkedIn, GitHub, site, Instagram, etc.) permettent d’adapter les réseaux à chaque secteur.

Les templates (v1, minimal, etc.) affichent ces mêmes sections ; seuls le design et le wording des libellés peuvent varier pour mieux coller à un secteur (ex. "Réalisations" au lieu de "Projets" dans un template dédié créatifs).
